> **Overhaul:** 2026-10-11 (seventy-fourth pass) — **Statement-fallback fixes, scrapers restored, older audit gap documented (v1.77.3).** Off Fin's go-ahead and ai's findings from Fin's screenshots of 2026-10-10 (reproduced offline against a copy of the live DB first). **SC-17 statement fallback (`etoro_reconcile.go`):** (1) crypto is scoped to wallet `eToro` — the preview had proposed closing 13 Binance/Ledger/MetaMask/Phantom holdings; the same rule SC-44 already had; applied crypto adds are now tagged wallet `eToro` (they were created with none, so they could never match again); (2) FT has no units column, so the preview now uses the **live SC-42 units** (`etoro_holdings_effective`) as 'FT units' and as what a drift proposal applies, and derives units (invested ÷ avg_open_price) **only for USD listings** — for GBp/JPY/EUR listings the division mixed a USD cost with a local-currency price and invented drift (RR.L +7,387%, 4063.T +15,624%); when FT already matches the live data a differing statement is shown in sync with a partial-close note and never applied (statements cannot see partial closes: RHM.DE); the statement's USD average price is no longer written into a non-USD listing's `avg_open_price` (it previously could be); (3) a statement ticker without an exchange suffix (`SU`) matches the single FT holding with that base (`SU.PA`) with needs_confirm and a note, instead of an add plus a closure; (4) the fallback's apply handler now writes `holdings_audit` rows (create/update/soft_delete, reason_code `etoro_statement_reconcile`, no trade snapshot). **Master-file import:** an eToro account statement uploaded there (it used to parse to an empty diff and look accepted) is detected (`etoro.LooksLikeStatement`: Account Summary + Closed Positions + Account Activity sheets) and rejected with a pointer to Performance → Upload statement / Stocks → Reconcile with eToro statement. Tests: `TestReconcileFallback` (13 crypto closures gone, GBp/EUR no false drift, partial-close, SU/SU.PA, FT-behind-live drift carries live figures, no-live-data rules, no statement USD avg on non-USD) and `TestLooksLikeStatement`. **Scrapers:** Playwright 1.60 + Chromium installed (Fin approved), `curran` joined group `ft` and owns the two output dirs (`/var/lib/ft` stays 750), and the Farside job was run once by hand and works (705 rows, newest 2026-10-09, 7-day −386.3, equal to the live card value); Capitol Trades is deliberately not run — the site answers 429 'Vercel Security Checkpoint' and needs a new source or retirement. Scripts, cron entries, a logrotate rule and `install.sh` are now in `ops/scrapers/` (REBUILD.md §8b updated). **Not done, awaiting Fin:** backfill of the older unaudited events (2026-09-27: 5 adds, 8 removals, 7 silent updates; 2026-10-06: 4 removals and 4 fallback adds — append-only audit rows, safe; the silent updates' prior values are not recoverable). **Left for ai's spec:** the performance importer's multi-year attribution, 'Income from Refunds' handling and USD/EUR warning. Supersedes v1.77.2.
